# Support

Use GitHub Issues for reproducible defects and bounded feature proposals.
Search existing issues first and provide:

- PatchHive version or commit
- browser and operating system
- sanitized reproduction steps
- expected and observed behavior
- whether a fresh browser profile reproduces the problem

Never attach secrets or a private workspace export. Use GitHub private
vulnerability reporting for security issues described in [SECURITY.md](SECURITY.md).

PatchHive is maintained on a best-effort open-source basis. There is no private
support channel or guaranteed response time.
